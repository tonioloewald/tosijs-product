tosijs-product

Cinematic scroll-linked product pages. Pure HTML. Zero JS orchestration.

Scroll = Progress

Every section converts scroll position into a normalized 0→1 value. Child elements animate in lockstep — no JavaScript required.

 
<!-- Define waypoints, apply styles. That's it. -->
<tosi-interpolator data-scroll-animate>
  <tosi-waypoint progress="0.0" style="opacity: 0;"></tosi-waypoint>
  <tosi-waypoint progress="0.5" style="opacity: 1;"></tosi-waypoint>
  <tosi-waypoint progress="1.0" style="opacity: 0;"></tosi-waypoint>
  <div>Your content here</div>
</tosi-interpolator>

Scroll Ranges

Constrain animations to any portion of a section's scroll using data-scroll-range.

Layer by Layer

Choreograph multiple elements within a single section, each with its own timing.

One Script Tag
