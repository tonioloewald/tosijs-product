## Blocker (confirmed — must resolve before tagging)

### B1. The release candidate exists only in the working tree; HEAD is not releasable
*(merged: correctness blocker + blast-radius blocker — same defect, both independently confirmed)*
`package.json`, `bun.lock`, 5 `src/*.ts` files, `tosijs-product-site.config.ts`, `README.md`, and a fully regenerated `dist/` + `docs/` (with untracked `docs/_chunks/`, `docs/version.json`) are all uncommitted. The dirty diff is the actual migration: peers tosijs `^1.7.5→^1.8.1`, tosijs-ui `^1.7.1→^1.12.7`, tjs-lang `^0.12→^0.13.6`, + chokidar `^5`.

- **HEAD is broken from a clean checkout**: verified via `git archive` + fresh `bun install` — `bun run build` fails (`Cannot find package 'chokidar'`; without a lockfile the `^1.7.1` peer floats tosijs-ui to 1.12.6, reproducing the `'marked'` failure). The originally reported red Tier-0 suite was an artifact of a stale partial `node_modules`, not a code defect — the working tree with a frozen install is green (48/48 tests, build succeeds).
- **Tagging HEAD as-is** publishes peer ranges (`tosijs-ui ^1.7.1`) describing a combination that was never tested and that admits the known-broken 1.12.6.
- **Committing blind** ships a migration diff nobody has consciously reviewed.
- `docs/` is the deployed GitHub Pages root (product.tosijs.net, CNAME present): deploying HEAD publishes a stale site; the current one exists only uncommitted.
- CHANGELOG `[Unreleased]` is empty and `package.json` still reads `0.6.5` for a claimed **major** release.

**Required before re-review**: deliberately commit (or revert) the migration as its own reviewed change — package.json + bun.lock, src edits, rebuilt docs/ (adding `_chunks/` and `version.json`, removing deleted chunks) — write the `[Unreleased]` CHANGELOG entry stating the new peer floors and whatever breaking change justifies the major bump, then prove the *committed* state green from a clean clone (`bun install && bun test && bun run build`). **Re-review scope**: Tier 0 (fresh install, tests, build) + documentation-accuracy over the migration diff.

### Resolve before release (confirmed security, severity minor)
**Live Mapbox token is unrestricted.** The `pk.eyJ1IjoicG9kcGVyc29u...` token committed in `src/tosi-scroll-map.ts:63`, `README.md:168`, `demo/docs.json`, and deployed `docs/` was tested live: the Mapbox API returns 200 even with a spoofed referer — any origin can bill tiles/geocoding to the account. ## Majors (confirmed — fix before or immediately after unblocking; none blocks alone)

### M1 (correctness, severity uncertain — owner may promote to blocker). `interpolateStrings` breaks hex-color waypoints
`src/tosi-interpolator.ts:59` checks numbers before colors, so hex colors interpolate as decimal digit-runs. Verified by execution: `#a0b0c0→#d0e0f0` never animates (stuck at start for all t); `#290000→#310000` @0.5 gives `#300000` not `#2d0000`; `#100000→#100001` yields invalid CSS `#100000.5` (declaration dropped, element flashes). Confirmed drift: sibling `interpolateThemeValue` (`src/tosi-product.ts:105`) got the isColor-first fix + wider named-color list; both copies originate in commit f47c60c. Current tests pass only because the demo colors luckily fall through to color-mix. **Fix**: hoist isColor above the numeric branch; unify the kernels (waypoints.ts) so they can't drift; add regression tests for `#290000→#310000` and `#a0b0c0→#d0e0f0`. Flagship component + documented feature — consider blocker.

### M2 (efficiency + blast-radius, merged). dist/index.js is a 5.38MB unminified IIFE that `main` and the `browser` condition resolve to — the tarball regression v0.6.5 was cut to fix is back, doubled
Verified: 5,383,314 B raw / 1.26MB gzip (was ~650KB gzip at 0.6.4, ~2.8MB unpacked at v0.6.5; now 5.5MB unpacked per `npm pack --dry-run`). `src/index-iife.ts` imports the full tosijs-ui 1.12 barrel, inlining CodeMirror into an un-splittable IIFE; both `Bun.build` calls in `bin/site.ts` omit `minify`. `main` and the `browser` exports condition point at this IIFE (no exports — broken as a module), so legacy resolvers and browser+require bundlers get 5.4MB of dead weight; even correct ESM consumers download a 1.3MB tarball that is 98% this file. CHANGELOG's 0.6.4 regression note understates the cost by 2x. **Fix**: `minify: true` on both builds; point `main`/`browser` at `./dist/module.js` (IIFE reachable only via explicit subpath/CDN URL); trim the IIFE to the components product pages need, or request an editor-free barrel upstream (see UPSTREAM); correct the CHANGELOG numbers. Exports-map changes can break CDN consumers pinning `dist/index.js` — re-review that diff under correctness + blast-radius.

### M3 (blast-radius). tosijs-ui is a required peer the shipped ESM never imports
Verified: `dist/module.js`'s only external import is `tosijs`; tosijs-ui is used only by `src/index-iife.ts` (bundled — no peer needed) and `bin/site.ts` (doc tooling). The pending `^1.12.7` hard peer forces a five-minor-line upgrade plus 12 `@codemirror/*` transitives onto every ESM consumer, and conflicts with consumers pinned to 1.7–1.11. **Fix**: move tosijs-ui to devDependencies (which also legitimately feeds `bin/site.ts`); keep only tosijs as a peer; if signaling the pairing matters, use `peerDependenciesMeta` optional.

### M4 (efficiency). Every scroll frame re-derives the entire animation model from the DOM
Verified in `src/tosi-product.ts:587` and siblings: all sections notified per rAF (even clamped at 0/1); per animator per frame: `querySelectorAll`, inline-style reads into fresh objects, sort (`tosi-interpolator.ts:102-121`), plus `readWaypoints`/`readMapWaypoints` re-parse + re-sort and `findScene`/`findMap` ancestor walks; `map.coords` and video `currentTime` written even while clamped. Contradicts the README's "high-performance" claim; allocation churn → GC jank on the exact low-end-mobile audience. **Fix (two-stage)**: (1) skip `_notify` when a section's progress is unchanged and skip clamped-endpoint writes; (2) cache the parsed animator/waypoint model, invalidated by the MutationObserver TosiProduct already owns.

# Remediation disposition — appended 2026-09-01, after the report above

*Added below the original report, which is unchanged. Verdict at the time: **BLOCK**.*

## Blocker

**B1 — the release candidate existed only in the working tree.** Resolved. The migration is a
deliberate change with a CHANGELOG entry naming the peer floors and the breaking changes, and
`package.json` reads `0.7.0`. Verified from a clean copy of exactly what would be committed:
`bun install --frozen-lockfile`, `tsc --noEmit` clean, 59/59 tests, `bun run build` green,
`npm pack` 15 files / 603kB. The report's *"HEAD is broken from a clean checkout"* was
pre-existing and this migration is its fix — HEAD's `tosijs-ui ^1.7.1` floats to 1.12.6, which
needs `chokidar` and `marked` that HEAD never declared.

## Majors

- **M1** (hex-color interpolation) — fixed. All three failures reproduced first, then the two
  drifted kernels were merged into one function in `src/waypoints.ts`, exported under both
  existing names. Four regression tests.
- **M2** (IIFE bloat / packaging) — fixed. Both bundles minified; no module condition resolves
  to the IIFE. See the size correction below.
- **M3** (phantom peer) — fixed as `peerDependenciesMeta` optional **plus** a devDependency.
  Optional alone breaks a fresh clone: this repo's own build needs `tosijs-ui/site`. Caught by
  the clean-clone check, which is the point of it.
- **M4** (per-frame re-derivation) — **deferred** to `TODO.md` with the two-stage plan. It is a
  behavioural change to the engine and wants its own change and its own verification.

## Security

**Unrestricted Mapbox token — accepted by the owner (2026-09-01)**, recorded in `TODO.md` under
"Accepted risk". It is a public token, and the demo needs a live one. Not a code change.

## Completeness gaps

- **Gap 1 (wrong diff basis)** — the cause of most of the others. Routed to the practices repo
  and now fixed at the source: the skill's trigger, and the harness's completeness critic, no
  longer key off the version letter, and the critic is told which lenses actually ran and is
  asked to check the diff basis first.
- **Gap 8 (haltijaDev / docs-publish audit)** — **audited, clean.** `docs/index.html` contains
  zero references to haltija or port 8701; the loader appears only in the *served* dev page, so
  the "injected at serve time, never in the built output" claim holds. The word appears in two
  `.map` files solely because tosijs-ui's own source mentions its `haltijaDev` implementation —
  no token, no endpoint. Sourcemaps were already published at HEAD (8 tracked `.map` files), so
  the untracked ones are rehashed replacements, not new exposure.
- Gaps 5, 6, 7 (mosaic CLI, component coverage, supply chain) — the CLI defects are **fixed**;
  coverage and SRI remain in `TODO.md`.

## Two things the review did not find

- **Five of seven type declarations were missing from the published tarball** — the build
  flattened only two out of `dist/src/` and `files` listed only those two. Confirmed against the
  real published 0.6.5 tarball; present since 0.6.4. Every TS consumer importing anything but
  the theme API got an unresolved module.
- **The build was not reproducible.** An incrementally-mutated `node_modules` left nested
  duplicate `@codemirror` copies, which the IIFE bundled once each: **625kB larger from the same
  lockfile**, silently. This also invalidated the first size numbers written into the CHANGELOG
  and into upstream issue #120 — both since corrected. Release artifacts are now built from
  `rm -rf node_modules && bun install --frozen-lockfile`, from which the build is
  byte-reproducible. Against the published 0.6.5 tarball the CDN bundle **shrank 11% gzip**; the
  first draft claimed a 19% growth.

**Re-review scope still outstanding:** a model pass (correctness + blast-radius, `depth: fast`)
over the remediation diff — in particular the exports-map change. Tier 0 is done, by hand, from
a clean tree.
